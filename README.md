## 📄 ¿Qué es Markdown?

Markdown es un lenguaje de marcado ligero que permite dar formato a texto de forma sencilla usando símbolos como `#`, `**` y `-`.

---

## 📌 ¿Para qué sirve?

Sirve para:

* Crear documentación
* Organizar contenido
* Escribir archivos README en proyectos

---

## 🌐 ¿Dónde se usa?

Se usa en plataformas como:

* GitHub
* Notion
* Slack
