## ¿Qué es Markdown?

Markdown es un lenguaje de marcado ligero que permite dar formato al texto de manera sencilla mediante el uso de símbolos fáciles de interpretar. Su principal ventaja es que no requiere herramientas complejas, ya que funciona con texto plano.

---

## ¿Para qué sirve?

Markdown se utiliza para:

* Crear documentación clara y organizada
* Escribir archivos README en proyectos
* Dar formato a textos sin necesidad de lenguajes complejos
* Mejorar la presentación de información

---

## ¿Dónde se usa?

Markdown es ampliamente utilizado en diversas plataformas, entre las que se destacan:

* GitHub (documentación de proyectos)
* Notion (organización académica y personal)
* Slack (comunicación con formato)
* Foros y blogs técnicos
